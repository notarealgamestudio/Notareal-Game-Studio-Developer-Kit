# Windows desktop build (v1.32)
The zip is split into parts because GitHub limits files to 100 MB.
Join them, then unzip:
- Windows (cmd): `copy /b NotarealStudio_Desktop_Windows.zip.part0+NotarealStudio_Desktop_Windows.zip.part1+NotarealStudio_Desktop_Windows.zip.part2 NotarealStudio_Desktop_Windows.zip`
- Mac/Linux: `cat NotarealStudio_Desktop_Windows.zip.part* > NotarealStudio_Desktop_Windows.zip`
